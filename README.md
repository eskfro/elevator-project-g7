# elevator-project-g7
Elevator project 

### Info
- Course: TTK4154 Real Time Programming
- Group: 7 
- Semester: 2026V
- Collaborators: Marius and Eskil

### Dependencies 
- Golang 1.20

### Build
- make build

### Run simulator
- ./out <id> <hardwarePort> <ordertablePort> <heartbeatPort>
- ./SimElevatorServer --port <hardwarePort>
or
- make sim1 || make sim2 || make sim3
- make simall

### Kill simulator 
- make kill
